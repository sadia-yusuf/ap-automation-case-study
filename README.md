# AP Invoice Automation: Case Study

One-page case study for an AI accounts-payable workflow: invoice PDFs arrive by email, OpenAI extracts the data, rule-based controls check it, exceptions go to a human, and approved bills post to QuickBooks Online with a full audit trail.

**Live page:** https://sadia-yusuf.github.io/ap-automation-case-study/

Built with n8n · OpenAI · QuickBooks Online · Gmail · Google Sheets.
Demo build on a QuickBooks sandbox company with synthetic invoices.

Full build: https://github.com/sadia-yusuf/novatech-ap-automation
